CVE-2015-3306
ProFTPD v1.3.5 		CRITICAL 9.8 Port 2121 (ftp) CISA KEV PoC Exploit ProFTPD mod_copy Unauthenticated Remote File Copy / RCE

mod_copy in ProFTPD 1.3.5 allows remote attackers to read and write arbitrary files on the server via SITE CPFR and SITE CPTO commands without authentication.

Fix: Upgrade ProFTPD to 1.3.5a or disable mod_copy in proftpd.conf.
CVE-2023-38408
OpenSSH v8.5p1 		CRITICAL 9.8 Port 2222 (ssh) CISA KEV PoC Exploit OpenSSH PKCS#11 Provider Remote Code Execution

Remote code execution in ssh-agent via PKCS#11 provider libraries when SSH agent forwarding is enabled.

Fix: Upgrade OpenSSH to version 9.3p2 or newer. Disable SSH Agent forwarding when connecting to untrusted hosts.
CVE-2024-6387
OpenSSH v8.5p1 		HIGH 8.1 Port 2222 (ssh) CISA KEV PoC Exploit OpenSSH regreSSHion - Remote Unauthenticated Code Execution

Signal handler race condition in OpenSSH server (sshd) allows unauthenticated remote code execution as root on glibc-based Linux systems.

Fix: Upgrade OpenSSH to version 9.8p1 or newer immediately, or set 'LoginGraceTime 0' as temporary workaround.
CVE-2021-41617
OpenSSH v8.5p1 		HIGH 7.0 Port 2222 (ssh) Theoretical OpenSSH Privilege Escalation via Supplementary Groups

OpenSSH failed to properly initialize supplementary groups when executing AuthorizedKeysCommand or AuthorizedPrincipalsCommand.

Fix: Upgrade OpenSSH to version 8.8p1 or higher.
CVE-2021-41773
Apache HTTP Server v2.4.49 		CRITICAL 9.8 Port 8088 (http) CISA KEV PoC Exploit Apache HTTP Server Path Traversal & Remote Code Execution

Flaw in path normalization in Apache 2.4.49 allows unauthenticated remote attackers to map URLs to files outside the document root (Path Traversal) and execute CGI scripts.

Fix: Immediately upgrade Apache HTTP Server to version 2.4.51 or higher.
CVE-2021-42013
Apache HTTP Server v2.4.49 		CRITICAL 9.8 Port 8088 (http) CISA KEV PoC Exploit Apache HTTP Server Path Traversal & RCE (Incomplete Fix for CVE-2021-41773)

Incomplete fix for CVE-2021-41773 allows path traversal and remote code execution via double-encoded dot segments (%%32%65).

Fix: Upgrade Apache HTTP Server to version 2.4.51 or newer.
